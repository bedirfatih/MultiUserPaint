Common paketi hem sunucu hem istemci tarafından ortaklaşa kullanılan sınıfları barındırır. Protokol tanımları, mesaj tipleri ve kodlama/çözme işlemleri burada yer alır.

C

ProtocolConstants

common   Protokol sabit değerleri — tüm sayısal parametreler tek yerde

Görev ve Tasarım Amacı

Protokolde kullanılan tüm sihirli sayılar, eşik değerleri ve boyutlar bu sınıfta public static final sabit olarak tanımlanmıştır. Herhangi bir değişiklik gerektiğinde tek bir dosyada güncelleme yeterlidir; sınıf kendi başına örneklenemez (private yapıcı).

Kritik Sabitler

public class ProtocolConstants {
    // Her mesajın başına eklenen 2 baytlık sihirli sayı.
    // Yanlış magic gelirse bağlantı anında kesilir.
    public static final short MAGIC = (short) 0xCAFE;

    // Protokol versiyonu. İleride farklı versiyonlarla uyumluluk için.
    public static final byte  VERSION = 0x01;

    // MAGIC(2) + VERSION(1) + TYPE(1) + PAYLOAD_LEN(4) = 8 bayt
    public static final int   HEADER_SIZE = 8;

    // Sunucu büyük piksel verisi için 10 MB'a izin veriyor.
    public static final int   MAX_PAYLOAD_SIZE = 10_485_760;

    // NIO okuma buffer'ı — küçük mesajlar için yeterli.
    public static final int   READ_BUFFER_SIZE = 65_536;

    public static final int   DEFAULT_PORT               = 9090;
    public static final int   AUTO_SAVE_INTERVAL_SECONDS = 60;
    public static final int   PING_INTERVAL_SECONDS      = 30;
    public static final int   KEEPALIVE_TIMEOUT_SECONDS  = 90;
    public static final int   DEFAULT_CANVAS_WIDTH       = 800;
    public static final int   DEFAULT_CANVAS_HEIGHT      = 600;

    private ProtocolConstants() {} // örneklenemez
}
Neden önemli? İstemci her 30 saniyede PING gönderir (PING_INTERVAL_SECONDS). Sunucu 90 saniye PING gelmezse bağlantıyı keser (KEEPALIVE_TIMEOUT_SECONDS). Otomatik kayıt 60 saniyede bir tetiklenir (AUTO_SAVE_INTERVAL_SECONDS). Bu üç değer birbirini doğrudan etkiler.

FSMState

common   Sonlu Durum Makinası durumları — hem sunucu hem istemci kullanır

Görev

Protokolün temelinde bir Sonlu Durum Makinası (FSM) yatar. Her bağlantı belirli bir durumda bulunur ve yalnızca o duruma uygun mesajları kabul eder. Tüm durum isimleri bu enum'da toplandığı için istemci ve sunucu aynı durum adlarını kullanır.

    RECONNECTING

T

MessageType

common   Tüm mesaj tipi kodları — 1 baytlık sayısal kod ↔ anlamlı isim

Görev

Wire format'ta her mesaj tipini 1 baytlık hexadecimal kod ile temsil eder. Bu enum sayesinde kod içinde 0x20 gibi sihirli sayılar yerine MessageType.DRAW_EVENT gibi okunabilir isimler kullanılır.

public enum MessageType {
    LOGIN_REQ          (0x01),
    LOGIN_OK           (0x02),
    LOGIN_ERR          (0x03),

    FILE_CREATE_REQ    (0x10),  FILE_CREATE_OK  (0x11),
    FILE_OPEN_REQ      (0x12),  FILE_OPEN_DATA  (0x13),
    FILE_LIST_REQ      (0x14),  FILE_LIST_RESP  (0x15),
    FILE_SAVE_REQ      (0x16),  FILE_SAVE_OK    (0x17),
    FILE_DELETE_REQ    (0x18),  FILE_DELETE_OK  (0x19),
    FILE_DELETE_ERR    (0x1A),

    DRAW_EVENT         (0x20),  DRAW_BROADCAST  (0x21),

    CLIPBOARD_COPY     (0x30),  CLIPBOARD_PASTE_REQ (0x31),
    CLIPBOARD_DATA     (0x32),  CLIPBOARD_CUT   (0x33),

    CANVAS_SNAPSHOT_REQ  (0x60),
    CANVAS_SNAPSHOT_DATA (0x61),
    CANVAS_UPDATE        (0x62),

    AUTOSAVE_NOTIFY    (0x50),
    PING (0xF0),  PONG (0xF1),
    ERROR (0xFF);

    private final int code;
    MessageType(int code) { this.code = code; }

    // Gelen bayt → enum dönüşümü. Bilinmeyen kod → IllegalArgumentException.
    public static MessageType fromCode(byte code) {
        int unsigned = code & 0xFF; // işaretsiz yap (0xF0 vs. -16 sorunu)
        for (MessageType t : values())
            if (t.code == unsigned) return t;
        throw new IllegalArgumentException("Unknown: 0x" + Integer.toHexString(unsigned));
    }
}
Kodlama şeması: 0x0x Login, 0x1x Dosya işlemleri, 0x2x Çizim, 0x3x Pano, 0x4x Kullanıcı olayları, 0x5x Bildirimler, 0x6x Canvas senkronizasyon, 0xFx Keepalive/Hata. Bu gruplandırma switch-case bloklarında mantıksal ayrım sağlar.
Java'da byte işaret sorunu: Java'da byte işaretli (-128..127). 0xF0 byte olarak -16'dır. Bu yüzden fromCode içinde code & 0xFF ile işaretsiz int'e çevrilir, karşılaştırma bu değerle yapılır.
M

Message

common   Çözümlenmiş mesajı taşıyan veri nesnesi (immutable)

Görev

Wire format'tan ayrıştırılan bir mesajı temsil eder. Tip ve ham payload baytlarını taşır. MessageFramer (sunucu) ve NetworkReader (istemci) mesajları tamamlandıktan sonra bu nesneye dönüştürür; dispatcher sınıfları bu nesneyi alarak ilgili handler'a yönlendirir.

public class Message {
    private final MessageType type;
    private final byte[]      payload;

    // Factory method — yapıcı private, kontrollü oluşturma
    public static Message of(MessageType type, byte[] payload) {
        return new Message(type, payload != null ? payload : new byte[0]);
    }
}
Tasarım: Message nesnesi immutable'dır — oluşturulunca değişmez. Payload ham bayttır; anlamlandırma işi MessageDecoder'a aittir. Bu ayrım MessageDecoder'ı bağımsız test edilebilir kılar.
E

MessageEncoder

common   Parametreleri wire-format bayt dizisine çevirir

Görev

Uygulama katmanındaki verileri (kullanıcı adı, koordinatlar, piksel verisi vb.) ağ üzerinden gönderilebilecek binary formata dönüştürür. Her mesaj tipi için ayrı bir encode*() metodu bulunur. Tüm metodlar static'tir, sınıf örneklenemez.

Wire Format — encode() metodu

public static byte[] encode(MessageType type, byte[] payload) {
    int payloadLen = payload != null ? payload.length : 0;
    byte[] frame = new byte[HEADER_SIZE + payloadLen]; // 8 + N bayt

    // Byte 0-1: MAGIC = 0xCAFE (big-endian)
    frame[0] = (byte) ((MAGIC >> 8) & 0xFF);   // 0xCA
    frame[1] = (byte)  (MAGIC        & 0xFF);   // 0xFE

    // Byte 2: VERSION = 0x01
    frame[2] = VERSION;

    // Byte 3: Mesaj tipi kodu
    frame[3] = type.getCode();

    // Byte 4-7: Payload uzunluğu (4 bayt, big-endian)
    frame[4] = (byte) ((payloadLen >> 24) & 0xFF);
    frame[5] = (byte) ((payloadLen >> 16) & 0xFF);
    frame[6] = (byte) ((payloadLen >>  8) & 0xFF);
    frame[7] = (byte)  (payloadLen        & 0xFF);

    // Byte 8+: Payload
    if (payload != null) System.arraycopy(payload, 0, frame, HEADER_SIZE, payloadLen);
    return frame;
}

buildWith() — Lambda ile Temiz Payload Oluşturma

// Fonksiyonel arayüz: DataOutputStream'e yazan lambda
@FunctionalInterface
private interface PayloadWriter {
    void write(DataOutputStream out) throws IOException;
}

private static byte[] buildWith(PayloadWriter writer, MessageType type) {
    ByteArrayOutputStream bos = new ByteArrayOutputStream();
    DataOutputStream      dos = new DataOutputStream(bos);
    writer.write(dos);   // lambda çağrısı: payload'ı dos'a yaz
    dos.flush();
    return encode(type, bos.toByteArray());
}

// Örnek kullanım — DRAW_EVENT kodlaması:
public static byte[] encodeDrawEvent(int fileId, byte toolType, int colorArgb,
                                      short strokeWidth, int x1, int y1, int x2, int y2) {
    return buildWith(out -> {
        out.writeInt(fileId);
        out.writeByte(toolType);
        out.writeInt(colorArgb);
        out.writeShort(strokeWidth);
        out.writeInt(x1); out.writeInt(y1);
        out.writeInt(x2); out.writeInt(y2);
    }, MessageType.DRAW_EVENT);
}
Neden DataOutputStream? writeInt(), writeShort(), writeLong() metodları big-endian formatında yazar — Java'nın varsayılan byte sırasıdır. Bu sayede platform bağımsızlığı sağlanır.
D

MessageDecoder

common   Ham payload baytlarını anlamlı Java nesnelerine dönüştürür

Görev

MessageEncoder'ın tam tersi işlevi görür. Her mesaj tipi için bir decode*() metodu vardır ve ilgili payload POJO sınıfını döndürür. Handler sınıfları ham bayt yerine bu POJO'larla çalışır.

Payload POJO'ları ve Çözümleme

// Payload için basit veri sınıfı — tüm alanlar public final
public static class DrawEventPayload {
    public final int   fileId;
    public final byte  toolType;
    public final int   colorArgb;
    public final short strokeWidth;
    public final int   x1, y1, x2, y2;
}

public static DrawEventPayload decodeDrawEvent(byte[] p) throws IOException {
    DataInputStream in = wrap(p); // byte[] → DataInputStream
    return new DrawEventPayload(
        in.readInt(),    // fileId
        in.readByte(),   // toolType
        in.readInt(),    // colorArgb
        in.readShort(),  // strokeWidth
        in.readInt(), in.readInt(),  // x1, y1
        in.readInt(), in.readInt()   // x2, y2
    );
}

String Çözümleme — readString()

// Protokol string kuralı: [2 bayt uzunluk][UTF-8 baytlar]
public static String readString(DataInputStream in) throws IOException {
    int    len   = in.readUnsignedShort(); // 0-65535, işaretsiz
    byte[] bytes = new byte[len];
    in.readFully(bytes);                   // tam olarak len bayt oku
    return new String(bytes, "UTF-8");
}
Neden readUnsignedShort()? Java'da readShort() işaretli döner (-32768..32767). String uzunluğu her zaman pozitif olduğundan işaretsiz (0-65535) okunması gerekir. readFully() ağ gecikmesi olsa bile tam sayıda bayt garantiler.

BÖLÜM 2 — Server Paketi

P

PaintServer

server   Sunucu giriş noktası — tüm bileşenleri oluşturur ve bağlar

Görev

Dependency Injection kalıbıyla sunucunun tüm bileşenlerini oluşturur, birbirine bağlar ve başlatır. Handler'lar, registry, disk havuzu, otomatik kayıt ve NIO döngüsü burada bir araya gelir. main() metodu komut satırı argümanını (port numarası) okur.

public void start() throws IOException {
    // 1. Altyapı katmanı
    registry  = new SessionRegistry();
    fileStore = new FileStore(filesDirPath);

    // 2. Disk I/O için ayrı thread havuzu (2 thread)
    // NIO thread'ini bloklamak yerine disk işlemleri buraya gönderilir
    diskPool = Executors.newFixedThreadPool(2, r -> {
        Thread t = new Thread(r, "DiskPool");
        t.setDaemon(true);
        return t;
    });

    // 3. Handler'lar — her birinin bağımlılıkları constructor'dan verilir
    LoginHandler     loginHandler     = new LoginHandler(registry);
    FileHandler      fileHandler      = new FileHandler(fileStore, registry, diskPool);
    DrawHandler      drawHandler      = new DrawHandler(registry);
    ClipboardHandler clipboardHandler = new ClipboardHandler(registry);

    // 4. Dispatcher tüm handler'ları bir arada yönetir
    MessageDispatcher dispatcher = new MessageDispatcher(
        loginHandler, fileHandler, drawHandler, clipboardHandler);

    // 5. Otomatik kayıt zamanlayıcısı
    autoSaveScheduler = new AutoSaveScheduler(registry, fileStore, fileHandler, 60);
    autoSaveScheduler.start();

    // 6. NIO döngüsü — son başlatılan, her şey hazır olmalı
    nioSelector = new NIOSelector(port, dispatcher, registry);
    nioSelector.start();
}

// JVM kapanırken düzgün kapatma (Ctrl+C)
Runtime.getRuntime().addShutdownHook(new Thread(server::stop, "Shutdown"));
Mimari karar: Disk I/O için 2 thread'lik ayrı havuz (DiskPool) kullanılır. Bu sayede dosya okuma/yazma işlemleri NIO thread'ini bloklamaz, diğer istemciler beklemez.
N

NIOSelector

server   Non-blocking I/O döngüsü — tek thread ile tüm istemciler yönetilir

Neden NIO?

Klasik blocking socket modelinde her istemci için ayrı bir thread açmak gerekir. N istemci = N thread demektir ve thread başına ~1 MB stack belleği harcanır. Java NIO (Non-blocking I/O) ise tek thread'in birden fazla kanalı aynı anda izlemesine olanak tanır. Selector sınıfı, hangi kanalın okuma/yazma için hazır olduğunu işletim sistemi düzeyinde tespit eder.

Başlatma — start()

public void start() throws IOException {
    selector = Selector.open();               // OS'a selector aç
    serverChannel = ServerSocketChannel.open();
    serverChannel.configureBlocking(false);   // KRİTİK: non-blocking mod
    serverChannel.bind(new InetSocketAddress(port));

    // Bu kanal yeni bağlantıları kabul edecek → OP_ACCEPT
    serverChannel.register(selector, SelectionKey.OP_ACCEPT);

    new Thread(this, "NIO-Selector").start();
}

Ana Döngü — run()

while (running) {
    // selector.select(1000): hazır kanal yoksa en fazla 1 sn bekle
    // Bu sürede keepalive kontrolü yapılabilir
    int ready = selector.select(1000);
    if (ready == 0) { checkKeepaliveTimeouts(); continue; }

    Iterator<SelectionKey> iter = selector.selectedKeys().iterator();
    while (iter.hasNext()) {
        SelectionKey key = iter.next();
        iter.remove(); // KRİTİK: işlenen key mutlaka kaldırılmalı
        if (!key.isValid()) continue;

        if      (key.isAcceptable()) acceptClient();
        else if (key.isReadable())   readFromClient(key);
        else if (key.isWritable())   writeToClient(key);
    }
    flushPendingWrites(); // yazılacak veri olan kanalları OP_WRITE'a ekle
}

Yeni Bağlantı — acceptClient()

private void acceptClient() throws IOException {
    SocketChannel clientChannel = serverChannel.accept();
    clientChannel.configureBlocking(false); // istemci de non-blocking

    int sessionId = sessionIdCounter.getAndIncrement(); // atomik ID üret
    ClientSession session = new ClientSession(sessionId, clientChannel);

    // Kanala session nesnesini ekle (attachment): key'den session'a erişim
    SelectionKey key = clientChannel.register(selector, SelectionKey.OP_READ);
    key.attach(session);
    registry.register(session);
}

Okuma ve MessageFramer Entegrasyonu

private void readFromClient(SelectionKey key) {
    ClientSession session = (ClientSession) key.attachment();
    int bytesRead = channel.read(session.readBuffer);
    if (bytesRead == -1) { closeSession(key, session); return; }

    session.readBuffer.flip(); // yazma → okuma moduna geç

    // Bir read çağrısında birden fazla mesaj gelebilir → döngü
    while (session.readBuffer.hasRemaining()) {
        Message msg = MessageFramer.feed(session, session.readBuffer);
        if (msg == null) break; // mesaj henüz tamamlanmadı

        boolean keepOpen = dispatcher.dispatch(session, msg);
        if (!keepOpen) { closeSession(key, session); return; }
    }
    session.readBuffer.compact(); // okunmayan baytları başa taşı
}

Yazma Kuyruğu Sistemi

// Handler mesaj ekler → writeQueue'ya offer() çağırır
// flushPendingWrites() kuyruğu dolu kanalları OP_WRITE'a kaydeder
private void flushPendingWrites() {
    for (SelectionKey key : selector.keys()) {
        ClientSession session = (ClientSession) key.attachment();
        if (session != null && !session.writeQueue.isEmpty())
            key.interestOps(SelectionKey.OP_READ | SelectionKey.OP_WRITE);
    }
}

// writeToClient(): kuyruktan al, kanala yaz
private void writeToClient(SelectionKey key) {
    while ((buf = session.writeQueue.peek()) != null) {
        channel.write(buf);
        if (buf.hasRemaining()) break; // kanal doldu, sonraki döngüde devam
        session.writeQueue.poll(); // tam yazıldı, kuyruğu temizle
    }
    if (session.writeQueue.isEmpty())
        key.interestOps(SelectionKey.OP_READ); // artık yazma bekleme
}

Keepalive Zaman Aşımı Kontrolü

private void checkKeepaliveTimeouts() {
    long now = System.currentTimeMillis();
    long timeoutMs = KEEPALIVE_TIMEOUT_SECONDS * 1000L;
    for (SelectionKey key : selector.keys()) {
        ClientSession session = (ClientSession) key.attachment();
        if (session != null && session.isLoggedIn()) {
            if (now - session.getLastPingTime() > timeoutMs) {
                closeSession(key, session); // 90s ping gelmedi → kes
            }
        }
    }
}
iter.remove() neden zorunlu? Selector, işlenen anahtarları otomatik temizlemez. Kaldırılmazsa aynı key sonsuz döngüde tekrar tekrar işlenir ve CPU %100'e çıkar. Bu NIO programlamasının en sık yapılan hatasıdır.
F

MessageFramer

server   TCP parçalı veri akışından tam mesajları birleştirir

Problem: TCP Stream Parçalama

TCP bir akım (stream) protokolüdür — mesaj sınırlarını bilmez. 800×600 = 480.000 piksel × 4 = ~1.9 MB'lık FILE_OPEN_DATA mesajı onlarca ayrı TCP segmentinde gelebilir. channel.read() her çağrıda farklı miktarda bayt döndürebilir. MessageFramer bu durumu 2 aşamalı birleştiriciyle çözer.

public static Message feed(ClientSession session, ByteBuffer src)
        throws ProtocolException {

    // ===== AŞAMA 1: 8 baytlık başlık biriktirilene kadar bekle =====
    if (session.payloadBuf == null) {
        transfer(src, session.headerBuf);         // gelen baytları headerBuf'a taşı
        if (session.headerBuf.hasRemaining()) return null; // daha eksik

        session.headerBuf.flip();
        int hi = session.headerBuf.get() & 0xFF;
        int lo = session.headerBuf.get() & 0xFF;

        // Magic kontrolü: 0xCA 0xFE değilse protokol hatası
        if (hi != MAGIC_HI || lo != MAGIC_LO)
            throw new ProtocolException("Invalid magic");

        session.headerBuf.get();                  // VERSION (şimdilik yok sayılır)
        session.pendingTypeCode = session.headerBuf.get(); // TYPE
        int payloadLen = session.headerBuf.getInt();       // PAYLOAD_LEN
        session.headerBuf.clear();                // sonraki mesaj için hazırla

        if (payloadLen < 0 || payloadLen > MAX_PAYLOAD_SIZE)
            throw new ProtocolException("Payload too large: " + payloadLen);

        // Tam bu boyutta payload buffer aç
        session.payloadBuf = ByteBuffer.allocate(payloadLen);
    }

    // ===== AŞAMA 2: payload dolana kadar bekle =====
    transfer(src, session.payloadBuf);
    if (session.payloadBuf.hasRemaining()) return null; // henüz eksik

    // Mesaj tamam — Message nesnesine çevir, payloadBuf sıfırla
    byte[] payload = session.payloadBuf.array();
    session.payloadBuf = null;
    return Message.of(MessageType.fromCode(session.pendingTypeCode), payload);
}

// Kaynak buffer'dan hedef buffer'a en fazla dst.remaining() kadar kopyala
private static void transfer(ByteBuffer src, ByteBuffer dst) {
    int n = Math.min(src.remaining(), dst.remaining());
    if (n == 0) return;
    int oldLimit = src.limit();
    src.limit(src.position() + n); // src'yi geçici olarak sınırla
    dst.put(src);
    src.limit(oldLimit);
}
Durum headerBuf veya payloadBuf içinde taşınır: Eğer payloadBuf != null ise Aşama 2'deyiz demektir. Bir sonraki feed() çağrısında kaldığımız yerden devam ederiz. Bu durum bilgisi ClientSession nesnesinde saklanır.
D

MessageDispatcher

server   FSM durumuna göre gelen mesajları doğru handler'a yönlendirir
public boolean dispatch(ClientSession session, Message msg) {
    switch (session.getState()) {
        case HANDSHAKE:
            // Yalnızca LOGIN_REQ kabul edilir
            if (msg.getType() != MessageType.LOGIN_REQ) {
                enqueue(session, encodeError("Login required first"));
                session.transitionTo(FSMState.ERROR);
                return false; // bağlantıyı kapat
            }
            loginHandler.handle(session, msg);
            return true;

        case ACTIVE:
            return dispatchActive(session, msg);

        case SAVING:
            // Diske yazım sırasında sadece PING kabul edilir
            if (msg.getType() == MessageType.PING) {
                enqueue(session, encodePong());
                session.updatePingTime();
            }
            return true; // diğer mesajlar yok sayılır
    }
}

private boolean dispatchActive(ClientSession session, Message msg) {
    switch (msg.getType()) {
        case FILE_CREATE_REQ:   fileHandler.handleCreate(session, msg);    break;
        case FILE_OPEN_REQ:     fileHandler.handleOpen(session, msg);      break;
        case FILE_SAVE_REQ:
            session.transitionTo(FSMState.SAVING);  // önce durum değişir
            fileHandler.handleSave(session, msg);   // sonra disk thread'e gönder
            break;
        case DRAW_EVENT:        drawHandler.handle(session, msg);          break;
        case CANVAS_SNAPSHOT_DATA: fileHandler.handleSnapshotData(session, msg); break;
        case CLIPBOARD_COPY:
        case CLIPBOARD_CUT:     clipboardHandler.handleCopyOrCut(session, msg); break;
        case CLIPBOARD_PASTE_REQ: clipboardHandler.handlePasteReq(session, msg); break;
        case PING:
            enqueue(session, encodePong()); session.updatePingTime(); break;
    }
    return true;
}
FILE_SAVE_REQ özel durumu: Durum geçişi (SAVING) disk işlemi başlamadan önce yapılır. Bu sayede disk thread'i çalışırken gelen başka mesajlar yok sayılır. Yazım bitince FileHandler ACTIVE'e geri döner.

ClientSession

server   Bir istemci bağlantısının tüm durumunu tutan veri nesnesi

Barındırdığı Veriler

public class ClientSession {
    // Kimlik
    private final int          sessionId;
    private final SocketChannel channel;

    private final Map<String,  ClientSession> byUsername   = new ConcurrentHashMap<>();

    public List<ClientSession> getSessionsWithFileOpen(int fileId) {
        List<ClientSession> result = new ArrayList<>();
        for (ClientSession s : bySessionId.values())
            if (s.isLoggedIn() && s.hasFileOpen(fileId)) result.add(s);
        return result;
    }

    // Tüm giriş yapmış istemcilere yayın (göndereni hariç tut)
    public void broadcastToAll(byte[] encoded, int excludeSessionId) {
        for (ClientSession s : bySessionId.values())
            if (s.getSessionId() != excludeSessionId && s.isLoggedIn())
                s.writeQueue.offer(ByteBuffer.wrap(encoded));
    }

    // Yalnızca belirtilen dosyayı açık olan istemcilere yayın
    public void broadcastToFileViewers(int fileId, byte[] encoded, int excludeSessionId) {
        for (ClientSession s : getSessionsWithFileOpen(fileId))
            if (s.getSessionId() != excludeSessionId)
                s.writeQueue.offer(ByteBuffer.wrap(encoded));
    }
}
broadcastToFileViewers() kritik önemi: DRAW_EVENT, CANVAS_UPDATE ve CLIPBOARD_DATA için sadece aynı dosyayı açık olan istemcilere gönderim yapılır. Bu sayede farklı dosyalar üzerinde çalışan istemciler birbirlerinin mesajlarıyla ilgilenmez.

// Pixsel verisi ↔ BufferedImage dönüşümü
public static byte[] imageToPixelBytes(BufferedImage img, int w, int h) {
    int[]  pixels = img.getRGB(0, 0, w, h, null, 0, w); // ARGB int dizisi
    byte[] data   = new byte[pixels.length * 4];
    for (int i = 0; i < pixels.length; i++) {
        int base    = i * 4;
        data[base]  = (byte) ((pixels[i] >> 24) & 0xFF); // A
        data[base+1]= (byte) ((pixels[i] >> 16) & 0xFF); // R
        data[base+2]= (byte) ((pixels[i] >>  8) & 0xFF); // G
        data[base+3]= (byte)  (pixels[i]        & 0xFF); // B
    }
    return data;
}
Dosyalar sunucuda files/file_1.png, files/file_2.png şeklinde PNG olarak saklanır. Protokolde ise ham ARGB bayt dizisi olarak taşınır. Okuma: PNG → ARGB bytes. Yazma: ARGB bytes → PNG.

LoginHandler

handler   Kullanıcı giriş doğrulaması ve HANDSHAKE → ACTIVE geçişi
private static final Pattern VALID_USERNAME = Pattern.compile("[a-zA-Z0-9_]{3,16}");

public void handle(ClientSession session, Message msg) throws IOException {
    String username = MessageDecoder.decodeLoginReq(msg.getPayload()).username;

    // Kural 1: Geçerli karakter seti (regex)
    if (!VALID_USERNAME.matcher(username).matches()) {
        enqueue(session, encodeLoginErr((byte) 0x02, "Invalid chars"));
        return; // HANDSHAKE'de kal, tekrar denenebilir
    }

    // Kural 2: Kullanıcı adı başka biri tarafından kullanılmıyor mu?
    if (registry.isUsernameTaken(username)) {
        enqueue(session, encodeLoginErr((byte) 0x01, "Username taken"));
        return;
    }

    // Geçerli: oturumu aktiflestir
    session.setUsername(username);
    session.transitionTo(FSMState.ACTIVE);      // FSM geçişi
    registry.registerUsername(session);

    enqueue(session, encodeLoginOk(session.getSessionId()));

    // Diğer istemcilere yeni kullanıcının bağlandığını bildir
    registry.broadcastToAll(encodeUserJoin(username), session.getSessionId());
}

public void handleOpen(ClientSession session, Message msg) {
    int fileId = MessageDecoder.decodeFileOpenReq(msg.getPayload());
    session.addOpenFile(fileId);

    List<ClientSession> activeViewers = registry.getSessionsWithFileOpen(fileId);
    // Gelen oturumu hariç tut (kendisi henüz eklendi)
    activeViewers.removeIf(s -> s.getSessionId() == session.getSessionId());

    if (!activeViewers.isEmpty()) {
        // Aktif görüntüleyici var → diskten eski veri yerine canlı canvas iste
        pendingOpens.computeIfAbsent(fileId, k -> new ArrayList<>())
            .add(new PendingOpenRequest(session, meta));
        enqueue(activeViewers.get(0), encodeCanvasSnapshotReq(fileId));
    } else {
        // Kimse açmamış → diskten oku (disk thread'inde)
        diskPool.submit(() -> {
            byte[] pixelData = fileStore.readFile(fileId);
            enqueue(session, encodeFileOpenData(fileId, ..., pixelData));
        });
    }
}

Snapshot Geldi — handleSnapshotData()

public void handleSnapshotData(ClientSession session, Message msg) {
    CanvasSnapshotDataPayload snap = MessageDecoder.decodeCanvasSnapshotData(msg.getPayload());

    // 1. Bekleyen yeni istemcilere gönder (canvas senkronizasyonu)
    List<PendingOpenRequest> pending = pendingOpens.remove(snap.fileId);
    if (pending != null) {
        for (PendingOpenRequest req : pending)
            enqueue(req.waitingSession, encodeFileOpenData(snap.fileId, ..., snap.pixelData));
    }

    // 2. Undo senkronizasyonu: diğer tüm görüntüleyicilere CANVAS_UPDATE yayınla
    byte[] update = encodeCanvasUpdate(snap.fileId, snap.width, snap.height, snap.pixelData);
    registry.broadcastToFileViewers(snap.fileId, update, session.getSessionId());
}
Bu metot iki farklı senaryoyu aynı anda çözer: (1) Yeni kullanıcı katılınca aktif canvas'ı alır, (2) Kullanıcı undo yapınca diğerlerine senkronize eder. Her iki durumda da istemci CANVAS_SNAPSHOT_DATA gönderir, sunucu aynı kodu çalıştırır.

    state = FSMState.CONNECTING;
    socket = new Socket(host, port);
    socket.setTcpNoDelay(true); // Nagle algoritmasını kapat — küçük paketler anında gider

public void run() {
    DataInputStream dis = new DataInputStream(in);
    while (running) {
        Message msg = readNextFrame(dis);           // bloklamalı okuma
        SwingUtilities.invokeLater(() -> onMessage.accept(msg)); // EDT'ye taşı
    }
    SwingUtilities.invokeLater(onDisconnect);        // bağlantı kesildi
}

private Message readNextFrame(DataInputStream dis) throws IOException {
    byte hi = dis.readByte(), lo = dis.readByte();    // MAGIC
    // ... magic kontrolü ...
    dis.readByte();                                    // VERSION
    byte typeCode  = dis.readByte();                  // TYPE
    int  payloadLen = dis.readInt();                  // PAYLOAD_LEN
    byte[] payload = new byte[payloadLen];
    dis.readFully(payload);                           // tam payload oku
    return Message.of(MessageType.fromCode(typeCode), payload);
}
SwingUtilities.invokeLater() neden gerekli? Swing thread-safe değildir. GUI güncellemeleri (canvas boyama, label değişimi) mutlaka EDT'de yapılmalıdır. NetworkReader ayrı bir daemon thread'de çalışır. invokeLater() mesajı EDT kuyruğuna ekler.

NetworkWriter

client   Daemon thread: yazma kuyruğunu drene ederek sunucuya gönderir
private final BlockingQueue<byte[]> writeQueue = new LinkedBlockingQueue<>();

// Herhangi bir thread'den çağrılabilir — thread-safe
public void send(byte[] data) {
    if (running) writeQueue.offer(data); // kuyruğa ekle, hemen dön
}

public void run() {
    while (running) {
        byte[] data = writeQueue.take(); // kuyruk boşsa burada bekler (block)
        out.write(data);
        out.flush();
    }
}
send() çağıran thread'i bloklamaz — veriyi kuyruğa ekler ve döner. Writer thread'i BlockingQueue.take()'de bekler, veri gelince yazar. Bu producter-consumer kalıbının klasik uygulamasıdır.

Undo Stack

private final Deque<BufferedImage> undoStack = new ArrayDeque<>();
private static final int MAX_UNDO = 20;

private void pushUndo() { // her mouse basışında çağrılır
    BufferedImage copy = new BufferedImage(canvasWidth, canvasHeight, TYPE_INT_ARGB);
    copy.createGraphics().drawImage(backBuffer, 0, 0, null); // derin kopya
    undoStack.push(copy);
    if (undoStack.size() > MAX_UNDO) undoStack.pollLast(); // en eski → sil
}

public void undo() {
    if (undoStack.isEmpty()) return;
    backBuffer = undoStack.pop(); // önceki durumu geri yükle
    repaint();
}

BFS Flood Fill

private void floodFill(int x, int y, Color fillColor) {
    int targetArgb = backBuffer.getRGB(x, y); // tıklanan noktanın rengi
    int fillArgb   = fillColor.getRGB();
    if (targetArgb == fillArgb) return; // zaten aynı renk

    Queue<Point> queue = new ArrayDeque<>();
    queue.add(new Point(x, y));

    while (!queue.isEmpty()) {
        Point p = queue.poll();
        if (p.x < 0 || p.x >= canvasWidth || p.y < 0 || p.y >= canvasHeight) continue;
        if (backBuffer.getRGB(p.x, p.y) != targetArgb) continue; // farklı renk
        backBuffer.setRGB(p.x, p.y, fillArgb);  // boyala
        // 4 komşuyu kuyruğa ekle (sağ, sol, aşağı, yukarı)
        queue.add(new Point(p.x+1, p.y)); queue.add(new Point(p.x-1, p.y));
        queue.add(new Point(p.x, p.y+1)); queue.add(new Point(p.x, p.y-1));
    }
}

Mesaj İşleme — onMessage()

// NetworkReader bu metodu EDT üzerinde çağırır
private void onMessage(Message msg) {
    switch (msg.getType()) {
        case LOGIN_OK:
            LoginOkPayload ok = decodeLoginOk(msg.getPayload());
            connection.onLoginOk(ok.sessionId); // durum CONNECTED'e geçer
            connection.sendFileListReq();
            break;

        case FILE_OPEN_DATA:
            FileOpenDataPayload data = decodeFileOpenData(msg.getPayload());
            CanvasPanel canvas = new CanvasPanel(data.width, data.height);
            canvas.fromPixelBytes(data.pixelData, data.width, data.height);
            addFileTab(data.fileId, data.filename, canvas); // yeni sekme
            break;

        case DRAW_BROADCAST:
            DrawBroadcastPayload draw = decodeDrawBroadcast(msg.getPayload());
            CanvasPanel c = openCanvases.get(draw.fileId);
            if (c != null) c.applyDrawCommand(draw); // karşı tarafın çizimini uygula
            break;

        case CANVAS_SNAPSHOT_REQ:
            // Sunucu canlı canvas istedi (yeni kullanıcı bağlandı)
            int reqFileId = decodeCanvasSnapshotReq(msg.getPayload());
            CanvasPanel sc = openCanvases.get(reqFileId);
            if (sc != null)
                connection.sendCanvasSnapshotData(reqFileId,
                    sc.getCanvasWidth(), sc.getCanvasHeight(), sc.toPixelBytes());
            break;

        case CANVAS_UPDATE:
            // Başka kullanıcı undo yaptı → canvas'ı güncelle
            CanvasUpdatePayload upd = decodeCanvasUpdate(msg.getPayload());
            CanvasPanel uc = openCanvases.get(upd.fileId);
            if (uc != null) uc.fromPixelBytes(upd.pixelData, upd.width, upd.height);
            break;

        case CLIPBOARD_DATA:
            // Yapıştırma verisi geldi — belirtilen koordinata uygula
            ClipboardDataPayload cp = decodeClipboardData(msg.getPayload());
            CanvasPanel pc = openCanvases.get(cp.fileId);
            if (pc != null) {
                BufferedImage img = pixelBytesToImage(cp.pixelData, cp.width, cp.height);
                pc.pasteImage(img, cp.x, cp.y);
            }
            break;
    }
}
openCanvases: Map<Integer, CanvasPanel> — fileId ile canvas eşlemesi, her mesajda doğru canvas'ı bulmak için kullanılır. Kullanıcı aynı anda birden fazla dosya açabilir; her biri ayrı sekme ve ayrı CanvasPanel'dir.
